# PLU コードベース仕様書

- 対象リポジトリ: `lvlatsu/playload`
- 対象ブランチ: `main`
- 調査日: 2026-11-19
- 対象: 現在のソースコード、ビルド・公開構成、テスト構成
- 対象外: ゲーム向け公開 API の詳細定義（既存の API リファレンスを正とする）

本書は、現時点のコードがどのような構造で動作しているかを記録する。設計上の希望や今後の拡張案を、実装済みの機能として扱わない。コード変更時には該当箇所とテストを再確認して更新する。

## セクション優先度の見方

各章に、今後の開発・保守でどれだけ先に把握／確認すべきかを示す優先度を付ける。これは章の重要度であり、未実装機能の実装順や作業期限を意味しない。

| 優先度 | 意味 |
| --- | --- |
| **P0：最重要** | 中核動作・データ互換性・実行分離・公開品質に直結する。変更時は影響範囲とテストを必ず確認する |
| **P1：高** | 日常的な利用体験や主要機能に関わる。関連機能の変更時に優先して確認する |
| **P2：標準** | 補助機能・周辺機能。該当箇所の変更時に確認する |
| **P3：低** | 主に紹介・一覧などの周辺領域。中核機能への影響は比較的小さい |

## 更新ルール

- 章の内容を変更するときは、該当する章ファイルを更新する。
- 章の追加・削除・名称変更時は、この目次と優先度一覧も更新する。
- 機能の実装状況と、テスト・実機での検証状況は分けて記録する。
