## 6. サウンド構成

**優先度：P2 — 主要機能の一つ。音声系変更時に確認。**

- `src/engine/sound.js` は ZX 128 PLAY 形式の文字列を解析し、イベント列へ変換する。
- AY クラスが 3 チャンネルの音声を生成する。矩形波、ノイズ、エンベロープ等を処理する。
- アプリ側の `Sound` は AudioContext と AudioWorklet を初期化し、音声処理をメイン UI から分離する。
- `Playback` がゲームフレームから届いたサウンド命令を音声側へ渡す。
- 録画時は利用可能な音声トラックを Canvas の映像ストリームへ追加する。
