# PLU 基本図形描画 API

> 状態：実装済み。2026-11-20。自動テストを追加。GitHub Actions と実機確認の結果は別途記録する。

## 1. 目的と設計方針

既存の put() / spr() / pcg を維持したまま、ゲームコードから任意のピクセル座標へ基本図形を描画する。

- 描画面は 160×144 ピクセル。Canvas への直接アクセスは提供しない。
- 座標はピクセル単位。小数は 0 方向へ切り捨てる。
- 図形の描画命令は毎フレーム登録する。BG・MG・FG も毎フレームクリアされる。
- 描画先は通常画面、または BG・MG・FG の各レイヤー。
- レイヤーの合成順は BG → MG → FG。通常の spr() と通常図形は従来の画面描画の上に描かれ、レイヤー群より下になる。
- 同じ描画面では呼び出し順に描画し、後の命令が前の命令を上書きする。
- 画面外はクリッピングする。アンチエイリアスは行わず、整数ドットで描画する。

## 2. API

| API | 用途 | 引数 |
| --- | --- | --- |
| upix(x, y, col) | 1ドット | 座標と色 |
| ulin(x1, y1, x2, y2, col) | 線分 | 始点・終点と色 |
| urec(x, y, w, h, lineCol, fillCol?) | 矩形・正方形 | 左上、幅、高さ、輪郭色、任意の塗り色 |
| uelp(x, y, w, h, lineCol, fillCol?) | 楕円・正円 | 左上、幅、高さ、輪郭色、任意の塗り色 |

4つの API は通常のトップレベルと BG / MG / FG の各レイヤーで利用できる。

```js
upix(10, 10, 7);
ulin(10, 10, 40, 30, 6);
urec(20, 20, 40, 24, 3);
urec(20, 20, 40, 24, 3, 4);
uelp(70, 20, 24, 24, 7);       // 正円
uelp(70, 20, 40, 20, 7, 2);   // 楕円
MG.uelp(70, 20, 40, 20, 7, 2);
```

## 3. 座標・寸法

- urec() と uelp() の x,y は図形の左上。
- w,h はピクセル単位の幅・高さ。図形の範囲は x〜x+w-1、y〜y+h-1。
- w と h が同じ uelp() は正円として扱う。円専用 API は設けない。
- 座標と寸法は有限数値を受け取り、Math.trunc 相当で整数化する。
- w または h が 0 以下なら矩形・楕円は何も描かない。
- upix() と ulin() も有限数値を整数化する。

## 4. 色と塗りつぶし

- 色番号は 0〜7。色 0 は黒であり、透明の意味を持たない。
- lineCol は必須の輪郭色。
- fillCol を省略した場合は輪郭のみ描画し、内部には触れない。
- fillCol を指定した場合、輪郭は lineCol、内部は fillCol で描画する。
- fillCol=0 は黒で塗りつぶす。
- 透明塗りつぶしという指定は設けない。何も描画しない部分はレイヤー上で透明のまま残り、下のレイヤーが見える。
- 同じレイヤー上に既に描かれたドットを消す機能ではない。消去・マスクは別機能として扱う。

## 5. 描画とレイヤー

- 各描画命令はフレーム単位のキューに登録され、描画時に画面バッファへ反映される。
- 通常の upix / ulin / urec / uelp は通常の spr() と同じ描画面に登録される。
- BG / MG / FG では、それぞれのレイヤー内で spr() と図形命令の呼び出し順を維持する。
- レイヤーは BG → MG → FG の順で合成する。
- 各レイヤーは毎フレーム消去されるため、表示を続けるには毎フレーム描画命令を呼び出す。
- 各描画キューは1フレームにつき最大128命令。上限超過時は既存スプライトと同じグリッチ通知を発生させる。

## 6. ラスタライズ

- upix() は対象の1ピクセルを書き込む。
- ulin() は画面境界へクリッピングした後、Bresenham 系の整数線分描画で始点・終点を含める。
- urec() は矩形の境界を lineCol で描き、fillCol があれば内部を塗る。
- uelp() は左上・幅・高さから楕円領域を求め、各行の左右端を輪郭として描く。fillCol があれば左右端の間を塗る。
- 描画はアンチエイリアスなし。画面内に限定して処理する。

## 7. エラーと境界

- 座標・寸法が有限数値でない場合は TypeError。
- 色番号が整数 0〜7 の範囲外の場合は RangeError。
- 画面外にはみ出した部分は描画しない。
- 画面外の線分は画面境界にクリッピングしてから描画し、極端に長い線分でも入力距離に比例したループを避ける。
- 幅・高さが 0 以下の矩形・楕円は何も描かない。

## 8. 初期版で扱わない機能

線幅、破線、アンチエイリアス、半透明、グラデーション、回転、任意マスク、消去・くり抜き、図形のヒットテストは対象外。

## 9. テスト・確認

自動テストでは、点・線・矩形・楕円、輪郭のみ、塗りつぶし、色0、画面端クリッピング、異常値、レイヤー合成、フレームごとのクリアを確認する。
