## 12. 現在の実装範囲と未実装・未確認事項

**優先度：P1 — 開発計画と現状認識の基準。**

### 12.1 機能別の実装進捗

進捗率は、現時点で確認できるコード上の実装範囲を基準にした目安である。機能の完成度や品質を保証する数値ではない。特に「実装済み」はコードの存在を確認した状態であり、最新環境での動作検証済みを意味しない。

| 機能領域 | 優先度 | 状態 | 進捗率 | 備考 |
| --- | --- | --- | ---: | --- |
| 基本ゲームエンジン | P0 | 実装済み | 100% | 既存 PlayLoad のエンジンを確認 |
| ゲーム実行の分離（iframe / Worker） | P0 | 実装済み | 100% | 実行境界とメッセージ検証を確認 |
| 基本描画・Canvas 表示 | P0 | 実装済み | 100% | 既存ピクセル面からの表示経路を確認 |
| URL ペイロードの圧縮・展開 | P0 | 実装済み | 100% | 新旧形式の読み込みを確認 |
| エディター・実行 UI | P1 | 実装済み | 100% | 既存アプリ機能を確認 |
| 入力・再生制御 | P1 | 実装済み | 100% | 既存の入力・フレーム制御を確認 |

### 進捗率の扱い

- **0%**：未着手、または対象機能の実装を確認できない。
- **1〜99%**：一部実装済み。何ができていて何が残っているかを備考に記録する。
- **100%**：定義した実装範囲のコードが揃っている。ただし、テスト・実機確認の完了を自動的に意味しない。
- **—（数値なし）**：実装率では表せず、環境・公開先・実機などで別途確認が必要。

状態は「未着手」「開発中」「実装済み」「要検証」を基本とする。実装済みと検証済みは混同しない。進捗率は機能の粒度や完了条件が変わった場合に見直す。


### 実装を確認したもの

- PlayLoad のゲームエンジンと既存ゲーム API
- BG・MG・FG の3層スプライト描画 API
- URL ペイロードの圧縮・展開と旧形式読み込み
- エディター、実行、入力、音声、Canvas 表示、CRT、録画
- iframe / Worker によるゲーム実行分離
- 紹介ページ、Arcade、サンプル・リファレンス生成
- Node.js / Playwright のテスト基盤
- GitHub Pages 用ビルド・デプロイワークフロー

### 現行コードで実装を確認できなかったもの

- ゲームコードから使う外部データ取得 API
- ゲームから Canvas へ直接描画する仕組み
- `line()`、`rect()`、`circle()` 等の図形描画 API
- ．えでぃ太との直接連携・アセット転送
- 対人通信・マルチプレイ機能
- サーバー側のユーザー作品保存・プロジェクト管理機能

これらは将来の構想として検討できるが、現行機能としては扱わない。

### 別途確認が必要なもの

- 公開 URL 上の最新デプロイと、GitHub Pages の実際の設定状態
- Cloudflare 側のルート・アカウント設定
- Android 実機を含むブラウザ別の最新動作
- 各ブラウザテストの直近の実行結果
- 外部素材のライセンスと、コード本体の MIT ライセンスの適用範囲
