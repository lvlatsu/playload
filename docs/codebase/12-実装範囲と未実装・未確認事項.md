## 12. 現在の実装範囲と未実装・未確認事項

**優先度：P1 — 開発計画と現状認識の基準。**

### 12.1 状態の定義

- **コード確認済み**：対象機能の実装が現行ソースに存在する。
- **テストコードあり**：対応する自動テストがリポジトリに存在する。実行成功を意味しない。
- **テスト実行確認済み**：対象コミットでテストを実行し、成功結果を確認した。
- **実機確認済み**：対象端末・ブラウザで操作・表示を確認した。
- **要確認**：現時点の証拠だけでは状態を確定できない。

### 12.3 基本図形 API の確定状況

次の4 API は仕様案だけでなく、現行エンジン・公開 API リファレンス・テストコードに存在する。

| API | 役割 |
| --- | --- |
| `upix(x, y, col)` | 1ピクセル |
| `ulin(x1, y1, x2, y2, col)` | 線分 |
| `urec(x, y, w, h, lineCol, fillCol?)` | 矩形 |
| `uelp(x, y, w, h, lineCol, fillCol?)` | 楕円・正円 |

`urec` / `uelp` の塗りつぶしは任意の第6引数で指定する。塗り色の省略は輪郭のみ、`fillCol=0` は黒で塗りつぶす。円専用 API や独立した `ufil` は設けない。各 API はトップレベルと BG・MG・FG の各レイヤーで利用できる。

詳細は17章・18章と `data/reference.json` を参照する。
