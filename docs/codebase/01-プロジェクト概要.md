## 1. プロジェクト概要

**優先度：P2 — 全体像を把握するための導入。**

PLU は PlayLoad を基盤とする JavaScript 製の小型ゲーム制作・実行環境である。ゲームのソースコードを圧縮して URL のハッシュに格納し、その URL を共有することで同じゲームを開ける構成を採る。

現在のリポジトリは PlayLoad のフォークであり、主要な実装は次の三領域に分かれる。

- ゲームエンジン: 画面・文字パターン・入力・サウンドの状態と更新を管理する。
- アプリケーション: エディター、ゲーム実行制御、入力 UI、画面表示、録画・保存を担当する。
- サイト／Arcade: 紹介ページと投稿作品一覧を生成・表示する。

### 現行の基本仕様

| 項目 | 実装 |
| --- | --- |
| 実行言語 | JavaScript (ES Modules) |
| 描画領域 | 160 × 144 ピクセル |
| 色 | 8 色のパレットインデックス |
| 文字・スプライト単位 | 8 × 8 ピクセル |
| 文字画面 | 20 列 × 18 行 |
| ゲーム更新 | 60 Hz を基準とする |
| 入力 | 上下左右、A・B の計 6 入力 |
| 音声 | 3 チャンネルの AY 系サウンド |
| 共有データ | JavaScript ソースを deflate-raw + Base64URL で URL に格納 |
| 新規共有サイズ上限 | 圧縮後 3000 bytes |
| 展開後ソース上限 | 1 MiB |

数値・制限の根拠は `src/engine/engine.js`、`src/payload.js`、`docs/design.md` と対応テストにある。
