## 1. 現在の描画関連 API

| API | 状態 | 役割・特徴 |
| --- | --- | --- |
| `cls(col)` | 実装済み | 文字画面全体を指定色で塗る。 |
| `put(cx, cy, str, col1?, col2?)` | 実装済み | 文字画面へ文字列を配置。文字座標、セル単位の前景色・背景色。 |
| `spr(x, y, str, col)` | 実装済み | 通常描画面へ8×8字形を配置。ピクセル座標、背景透明、毎フレーム登録。 |
| `upix(x, y, col)` | 実装済み | 任意ピクセル座標に1ドット描画。 |
| `ulin(x1, y1, x2, y2, col)` | 実装済み | クリッピング対応の線分描画。 |
| `urec(x, y, w, h, lineCol, fillCol?)` | 実装済み | 左上・幅・高さで矩形を描画。塗り色は任意。 |
| `uelp(x, y, w, h, lineCol, fillCol?)` | 実装済み | 楕円を描画。幅と高さが同じなら正円。塗り色は任意。 |
| `BG.spr()` / `MG.spr()` / `FG.spr()` | 実装済み | 各レイヤーへスプライトを登録。 |
| `BG.upix/ulin/urec/uelp` 等 | 実装済み | 基本図形 API は各レイヤーでも同じ引数で利用可能。 |
| `pcg[chr].pat` / `.col` | 実装済み | 文字ごとの8×8ドットパターンと標準色を定義。 |
| `scr[cy][cx]` | 実装済み | 文字画面セルの文字と色を参照・編集。 |

### 基本図形 API の重要な規則

- 座標はピクセル単位。数値は有限値を受け取り、0方向へ整数化する。
- `urec` / `uelp` の `x,y` は左上、`w,h` は幅・高さ。
- `fillCol` を省略すると輪郭のみ。内部の既存ピクセルは変更しない。
- `fillCol=0` は黒で塗りつぶす。色0は透明ではない。
- 円専用 API は設けず、`uelp(w,h)` で正円・楕円を表現する。
- 画面外はクリッピング。アンチエイリアスなし。
- 基本図形 API は通常面と BG・MG・FG の各レイヤーで使用できる。

## 2. 描画順・フレーム処理

レンダリング順は次のとおり。

1. 文字画面
2. 通常の `spr()` と通常の基本図形描画
3. BG
4. MG
5. FG

BG・MG・FG の各描画キューは毎フレーム初期化される。各レイヤーは固定順で合成され、レイヤー間の呼び出し順では前後関係は変わらない。同じ描画面の中では登録順を維持する。各描画キューは1フレーム最大128命令。

## 3. 描画以外の関連 API

- `ucpl.set()` / `setAll()` / `get()` / `reset()`：実行時 RGB パレット操作。詳細は20章。
- `urnd()`、`usin()`、`ucos()`、`utan()`、`usqr()`、`uabs()`、`uflr()`、`ucei()`、`umin()`、`umax()`、`upow()`、`uatan2()`：数学 API。詳細は21章。
