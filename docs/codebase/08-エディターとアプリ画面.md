## 8. エディターとアプリ画面

**優先度：P1 — 制作・実行の主要なユーザー体験。**

`src/app/index.html` がアプリの基本 DOM を定義し、`main.js` が操作を結び付ける。

主な画面・機能:
- Play / Info のタブ
- JavaScript コードエディター、シンタックスハイライト、整形
- JavaScript ファイルの読み込み
- Run / Pause、実行エラー表示と該当行への移動
- CRT 表示とサウンドの切り替え
- 圧縮ペイロードサイズ表示
- キーボード・タッチ・ゲームパッド操作
- スクリーンショットと WebM 録画
- API リファレンス、文字・絵文字カタログ、サンプル一覧
- 小さい画面向けのツール表示切り替え

アプリの初期コード、サンプル一覧、API リファレンスは生成物を含むため、生成元と生成スクリプトを確認して編集する。
