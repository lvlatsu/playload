# PLU コードベース仕様書 — リポジトリ構成

> 章単位の分割ファイルです。全体の目次・優先度一覧は [`../PLU_CODEBASE_SPEC.md`](../PLU_CODEBASE_SPEC.md) を参照してください。

## 2. リポジトリ構成

**優先度：P1 — 変更対象ファイルと責務を特定する基礎。**

### 2.1 アプリケーション本体

| パス | 役割 |
| --- | --- |
| `src/app/main.js` | アプリの起点。画面、エディター、URL、入力、実行・停止、各機能を統括 |
| `src/app/index.html` | アプリの HTML テンプレート |
| `src/app/style.css` | アプリ画面のスタイル |
| `src/app/runtime.js` | Worker の起動・停止・フレーム要求・監視、および音声制御クラス |
| `src/app/game-sandbox.js` | 不透明オリジンの sandbox iframe を作り、MessageChannel を接続 |
| `src/app/game-host.js` | iframe 内で Worker を起動し、親側とのメッセージを中継 |
| `src/app/game-worker.js` | ゲームコードを実行し、エンジン更新結果を返す |
| `src/app/game-messages.js` | Worker 境界のメッセージ形式・内容・サイズの検証 |
| `src/app/display.js` | ピクセル配列の差分判定と通常表示用 RGBA 変換 |
| `src/app/crt.js` | WebGL による CRT 表示 |
| `src/app/playback.js` | フレーム進行、停止・再開、音声・録画の同期 |
| `src/app/capture.js` | Canvas 映像と音声の録画、WebM 保存処理 |
| `src/app/webm.js` | WebM のバッファリング・書き出し |
| `src/app/editor-highlighter.js`, `highlighter.js` | コードエディターのハイライト |
| `src/app/editor-history.js` | エディターの編集履歴 |
| `src/app/formatter.js` | コード整形 |
| `src/app/keys.js` | キー入力関連の補助処理 |
| `src/app/examples.js` | 生成されたサンプル一覧・初期コード |
| `src/app/fonts.css` | アプリで使うフォント定義 |

### 2.2 エンジン・ペイロード

| パス | 役割 |
| --- | --- |
| `src/engine/engine.js` | ゲーム状態、描画、文字パターン、入力、ゲーム向け API |
| `src/engine/glyphs.js` | 内蔵文字・記号・絵文字の字形データ（生成物） |
| `src/engine/sound.js` | ZX 128 PLAY 形式のスコア解析と AY 系音源合成 |
| `src/payload.js` | ソースの圧縮・展開、URL 生成、容量判定 |

### 2.3 サイト・作品集

| パス | 役割 |
| --- | --- |
| `src/site/index.html`, `src/site/index.md` | 紹介ページのテンプレート・本文 |
| `src/site/main.js`, `src/site/style.css` | 紹介ページの動作・スタイル |
| `src/arcade/index.html`, `src/arcade/style.css` | Arcade ページのテンプレート・スタイル |
| `data/arcade.json` | Arcade 掲載作品の情報と共有 URL |
| `assets/images/arcade/` | Arcade 掲載用スクリーンショット |
| `data/reference.json` | アプリ内 API／サウンドリファレンスの生成元 |
| `data/examples.json`, `examples/` | サンプルゲームの生成元・ソース |

### 2.4 開発・生成・検証

| パス | 役割 |
| --- | --- |
| `scripts/build.js` | esbuild を使ったサイト一式のビルド |
| `scripts/reference.js` | API リファレンス HTML の生成 |
| `scripts/generate-examples.js` | サンプル一覧の生成 |
| `scripts/generate-glyphs.js` | 字形データの生成 |
| `scripts/generate-screenshots.js` | サンプル画像の生成 |
| `scripts/wrangler.mjs` | Wrangler 実行時の補助 |
| `tests/` | 単体・統合・ブラウザテスト |
| `docs/` | 設計方針、履歴、描画出力などの開発文書 |
| `.github/workflows/deploy-pages.yml` | GitHub Pages のビルド・デプロイ |
